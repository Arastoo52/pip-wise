# PipWise — Forex Review & Broker Comparison Platform

PipWise is a high-performance, modern Forex broker review and comparison web application featuring interactive 3D elements, real-time comparison tables, macOS-inspired dock navigation, and interactive companions.

## Tech Stack
- **Framework**: React 19 + Vite 8
- **Animation**: Framer Motion & CSS hardware-accelerated transforms
- **Smooth Scrolling**: Lenis
- **Styling**: Vanilla CSS with modern tokens & glassmorphism

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation & Running

1. Navigate to the frontend directory:
```bash
cd frontend
npm install
npm run dev
```

Or from the root directory:
```bash
npm run dev
```

2. Build for production:
```bash
npm run build
```
